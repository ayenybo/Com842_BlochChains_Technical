# COMP842 – Applied Blockchains and Cryptocurrencies

## Technical Assessment Portfolio – Semester 2, 2026

This repository contains the practical implementations completed for the **COMP842 Individual Technical Assessment**.

## Exercises

### Exercise 1 – Blockchain Structure and Tamper Detection
- Block class implementation
- SHA-256 block hashing
- Merkle Root calculation
- Blockchain creation and validation
- Tamper detection

### Exercise 2 – Proof of Work
- Proof-of-Work implementation
- Block mining and nonce calculation
- Difficulty-based hash validation
- Mining performance analysis

### Exercise 3 – Elliptic Curve Cryptography (ECDSA)
- ECDSA public/private key pair generation
- Private and public key representation
- Digital signature generation
- Signature verification

### Exercise 4 – Blockchain Transaction
- Blockchain transaction implementation
- Transaction signing
- Transaction verification
- Demonstration of blockchain security concepts

## Technologies Used
